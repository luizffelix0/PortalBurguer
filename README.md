# 🍔 PortalBurguer

> Projeto de modificação de um site de hamburgueria, utilizando Flexbox para aprimorar a organização e disposição dos elementos no CSS.

## 📖 Sobre o projeto

O **PortalBurguer** é um projeto desenvolvido durante os estudos no SENAI, com o objetivo de praticar e aprofundar os conhecimentos em CSS, especialmente na utilização do Flexbox.

A proposta foi modificar um site de hamburgueria já existente, trabalhando na organização dos elementos, estrutura visual e layout da página.

## ⚙️ Aprendizados e implementações

- 🍔 Modificação de um site de hamburgueria existente.
- 📐 Utilização do Flexbox para organização dos elementos.
- 🎨 Prática de estilização e estruturação de layouts com CSS.
- 💻 Aplicação dos conhecimentos de desenvolvimento web adquiridos em aula.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- Flexbox

## 🎓 Objetivo

Projeto acadêmico desenvolvido para praticar CSS, compreender o funcionamento do Flexbox e aprimorar habilidades de estilização e organização de páginas web.

## ▶️ Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/luizffelix0/PortalBurguer.git
   ```
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra-o no navegador para visualizar o site.
